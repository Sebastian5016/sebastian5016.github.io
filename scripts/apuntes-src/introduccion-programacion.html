1. ¿Qué es programar?

Programar es escribir instrucciones precisas para que una computadora resuelva un problema. Antes de escribir código pensamos un algoritmo: una secuencia ordenada y finita de pasos.

Ejemplo de algoritmo: preparar un mate. 1) Llenar el mate con yerba. 2) Inclinarlo. 3) Calentar agua sin que hierva. 4) Cebar. 5) Repetir el paso 4 mientras haya ganas.

2. Variables

Una variable es una “caja” con nombre donde guardamos un dato. En Python no hace falta declarar el tipo.

nombre = "Lucía"   # texto (str)
edad = 15          # entero (int)
altura = 1.62      # decimal (float)
estudia = True     # lógico (bool)

3. Entrada y salida

nombre = input("¿Cómo te llamás? ")
print("Hola,", nombre)
edad = int(input("¿Edad? "))   # input devuelve texto: lo convertimos a número

4. Condicionales

Permiten que el programa tome decisiones.

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")

Operadores de comparación: == igual, != distinto, <, >, <=, >=. Operadores lógicos: and, or, not.

6. Errores frecuentes

  • IndentationError: en Python la sangría (espacios al inicio) es obligatoria dentro de un bloque.
  • TypeError al sumar: "5" + 3 falla porque se mezcla texto con número.
  • Olvidar los dos puntos al final de if, for, while y def.
