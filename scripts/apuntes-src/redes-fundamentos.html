1. ¿Qué es una red?

Un conjunto de dispositivos conectados que comparten información y recursos. Internet es una red de redes.

2. Tipos por alcance

TipoAlcanceEjemplo
PANPersonal (metros)Auriculares Bluetooth
LANEdificioRed de la escuela
MANCiudadRed de un municipio
WANPaísesInternet

3. Dispositivos

  • Switch: conecta equipos dentro de la misma red local.
  • Router: conecta redes distintas y decide la ruta de los paquetes.
  • Access point: da acceso inalámbrico (Wi‑Fi).
  • Módem: convierte la señal del proveedor de Internet.

4. Direcciones IP

Cada dispositivo tiene una dirección IP, por ejemplo 192.168.1.25. La máscara (255.255.255.0 o /24) indica qué parte identifica a la red y qué parte al equipo. La puerta de enlace es el router por el que se sale a otras redes.

DNS traduce nombres en direcciones: cuando escribís wikipedia.org, un servidor DNS responde con su IP.

5. Comandos útiles

ipconfig        (Windows)  /  ip a   (Linux)   → ver mi IP
ping 8.8.8.8    → ¿llego a ese equipo?
tracert google.com  /  traceroute google.com → ¿por dónde pasan los paquetes?
nslookup google.com → ¿qué IP tiene ese nombre?

Actividad

Ejecutá ipconfig (o ip a) en tu computadora. Anotá tu IP, máscara y puerta de enlace. Después hacé tracert a un sitio y contá cuántos saltos hay.
