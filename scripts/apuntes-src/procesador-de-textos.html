Al terminar vas a poder:
  • Usar estilos de título y generar un índice automático.
  • Insertar tablas, imágenes con texto alternativo y notas al pie.
  • Entregar un trabajo prolijo en PDF.

1. Estilos: la clave de un documento ordenado

No “agrandes la letra” a mano para los títulos: usá Título 1, Título 2, etc. Así el documento queda estructurado, accesible y podés crear un índice en un clic.

2. Índice automático

  • Word: Referencias → Tabla de contenido.
  • Google Docs: Insertar → Índice.

3. Atajos que ahorran tiempo

AcciónAtajo
Negrita / cursivaCtrl + B / Ctrl + I (Word: Ctrl + N / Ctrl + K en español)
DeshacerCtrl + Z
BuscarCtrl + F (Word en español: Ctrl + B)
Salto de páginaCtrl + Enter

4. Imágenes y tablas

  • Agregá texto alternativo a cada imagen (clic derecho → Texto alternativo).
  • Usá tablas para datos, no para acomodar texto.
  • Citá la fuente de cada imagen que no sea tuya.

5. Entrega

Exportá a PDF (Archivo → Descargar / Guardar como → PDF) para que se vea igual en cualquier dispositivo. Nombrá el archivo así: Apellido_Materia_Trabajo.pdf.

Actividad

Armá un informe de 3 páginas sobre un tema de tecnología con portada, índice automático, dos títulos de nivel 1, una tabla, una imagen con texto alternativo y bibliografía.
