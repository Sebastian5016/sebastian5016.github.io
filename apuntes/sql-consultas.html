Bases de datos y consultas SQL

Nivel: IntermedioLectura: 16 minActualizado: 2026-11
Al terminar vas a poder:
  • Explicar qué es una base de datos relacional.
  • Identificar claves primarias y foráneas.
  • Escribir consultas SQL con filtros, orden, uniones y agrupamientos.

1. Conceptos

  • Tabla: conjunto de datos sobre un mismo tema (filas = registros, columnas = campos).
  • Clave primaria (PK): identifica cada fila de forma única.
  • Clave foránea (FK): campo que apunta a la PK de otra tabla y crea la relación.

2. Consultas básicas

SELECT titulo, autor FROM libros;               -- elegir columnas
SELECT * FROM libros WHERE anio < 1950;          -- filtrar
SELECT * FROM libros ORDER BY anio DESC;         -- ordenar
SELECT COUNT(*) FROM libros;                     -- contar

3. Uniones (JOIN)

SELECT e.codigo, m.nombre, n.nota
FROM notas n
JOIN estudiantes e ON e.id = n.estudiante_id
JOIN materias m    ON m.id = n.materia_id;

4. Agrupamientos

SELECT materia_id, AVG(nota) AS promedio
FROM notas
GROUP BY materia_id
HAVING AVG(nota) >= 6;
