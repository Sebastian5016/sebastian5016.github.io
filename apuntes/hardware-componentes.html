Hardware: componentes de una computadora

Nivel: InicialLectura: 12 minActualizado: 2026-11
Al terminar vas a poder:
  • Reconocer los componentes principales de una computadora.
  • Explicar la función de cada uno.
  • Leer las especificaciones de un equipo y compararlas.

1. Hardware y software

El hardware es la parte física (lo que se puede tocar). El software son los programas e instrucciones. Uno no funciona sin el otro.

2. Modelo de funcionamiento

Toda computadora sigue el ciclo Entrada → Procesamiento → Salida, con Almacenamiento para guardar datos.

3. Componentes principales

ComponenteFunciónDato que importa
CPU (procesador)Ejecuta las instrucciones. Es el “cerebro”.Núcleos y frecuencia (GHz)
Memoria RAMGuarda temporalmente lo que se está usando. Se borra al apagar.Capacidad (GB)
Almacenamiento (SSD / HDD)Guarda datos de forma permanente.Capacidad y tipo (SSD es más rápido)
Placa madreConecta todos los componentes.Compatibilidad (socket, ranuras)
Fuente de alimentaciónConvierte la corriente de la red para los componentes.Potencia (W)
GPU (placa de video)Procesa imágenes y video.Memoria de video

4. Periféricos

  • Entrada: teclado, mouse, micrófono, escáner, cámara.
  • Salida: monitor, impresora, parlantes.
  • Entrada/Salida: pantalla táctil, pendrive, impresora multifunción.

5. Unidades de información

1 byte = 8 bits · 1 KB ≈ 1.000 bytes · 1 MB ≈ 1.000 KB · 1 GB ≈ 1.000 MB · 1 TB ≈ 1.000 GB.

Actividad

Buscá dos computadoras en una tienda en línea. Armá una tabla comparando CPU, RAM, almacenamiento y precio. ¿Cuál recomendarías para un estudiante que programa y por qué?
