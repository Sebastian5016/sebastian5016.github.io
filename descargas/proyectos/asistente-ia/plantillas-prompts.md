# Plantillas de prompts para estudiar con IA

> Regla de oro: la IA te ayuda a pensar, no piensa por vos.
> Siempre verificá la información en al menos una fuente confiable.

## 1. Explicame un tema
```
Actuá como profesor de [materia] de secundario.
Explicame [tema] en no más de 200 palabras, con un ejemplo de la vida cotidiana.
Después haceme 3 preguntas para comprobar si lo entendí. No me des las respuestas.
```

## 2. Corregí mi razonamiento (no mi tarea)
```
Resolví este ejercicio así: [tu resolución].
No me des la respuesta correcta. Decime en qué paso puede haber un error
y dame una pista para que lo encuentre yo.
```

## 3. Practicar para una evaluación
```
Generá 5 ejercicios de [tema], de dificultad creciente.
Numeralos y no incluyas las soluciones hasta que te las pida.
```

## 4. Programación: entender un error
```
Este código en [lenguaje] me da el error: [mensaje].
Explicame qué significa el error y qué debería revisar.
No reescribas el programa completo.
```

## 5. Verificación
```
¿Qué partes de tu respuesta anterior podrían ser incorrectas o estar desactualizadas?
¿Qué fuentes confiables podría consultar para verificarlas?
```

## Checklist antes de usar una respuesta
- [ ] ¿La entendí y puedo explicarla con mis palabras?
- [ ] ¿La comparé con el apunte o con otra fuente?
- [ ] ¿Revisé datos, fechas y nombres?
- [ ] ¿Indiqué que usé IA si la consigna lo pide?
